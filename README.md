# Songbird Website

A responsive, storybook-inspired website concept for Christie Kanska's Songbird creative world.

## Run locally

```bash
npm start
```

Then open `http://127.0.0.1:4173`.

## Deploy to Vercel

Import the repository into Vercel. The included `vercel.json` runs the static
build and publishes the generated `dist/` directory automatically.

To verify the production build locally:

```bash
npm run build
```

## Project structure

- `index.html` — page content and accessible structure
- `styles.css` — visual system and responsive layouts
- `script.js` — navigation, reveal effects, and story modal
- `assets/` — supplied Songbird artwork
